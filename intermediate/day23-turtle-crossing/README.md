# 🐢 Turtle Crossing Game

A classic Turtle Crossing game built with Python and the Turtle module as part of the **100 Days of Code** challenge.

The objective is simple: help the turtle cross the road while avoiding incoming traffic. Each time the turtle reaches the finish line, the level increases and the cars move faster, making the game progressively more challenging.

---

## 🚀 Features

- Player-controlled turtle movement
- Random car generation
- Collision detection system
- Level progression
- Dynamic difficulty increase
- Score and level tracking
- Game over screen
- Smooth animation using manual screen updates

---

## 🛠️ Technologies Used

- Python 3
- Turtle
- Object-Oriented Programming (OOP)

Navigate to the project folder:

```bash
cd intermediate/day23-turtle-crossing
```

Run the game:
