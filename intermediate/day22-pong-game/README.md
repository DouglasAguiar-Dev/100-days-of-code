# 🏓 Pong Game

A classic Pong game built with Python and the Turtle module as part of the **100 Days of Code** challenge.

The objective is simple: control your paddle, bounce the ball back to your opponent, and score points by making the other player miss the ball.

---

## 🚀 Features

- Two-player gameplay
- Paddle movement using the keyboard
- Ball movement and physics
- Collision detection with paddles
- Collision detection with walls
- Dynamic ball speed increase
- Score tracking system
- Center net rendering

---

## 🛠️ Technologies Used

- Python 3
- Turtle
- Object-Oriented Programming (OOP)
